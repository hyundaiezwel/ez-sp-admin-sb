# UI/UX 규약

SB 목업을 검토하며 나온 지적을 **화면 한 장의 수정이 아니라 공통 규칙**으로 남긴다.
새 화면을 만들거나 고칠 때 이 문서를 따른다. 규칙마다 번호(`UI-nn`)가 있고, 검사 스크립트와 코드 주석이 이 번호로 서로를 가리킨다.

- **구현** — 규칙을 지키게 만드는 공통 코드. 화면이 따로 할 일이 없으면 "공통"이라고 적었다.
- **검사** — 어기면 잡아내는 자동 검사.
  - `check:sb` — `SB_BANNED_FILE=<금지어 파일> npm run check:sb`. 정적 검사라 서버가 필요 없다.
  - `check:responsive` — `npm run dev`를 띄운 뒤 `SB_URL=… npm run check:responsive`. 77개 화면을 1280·1024 폭으로 실제로 열어서 잰다.
- 새 지적이 나오면 **이 문서에 규칙을 먼저 추가**하고, 검사로 막을 수 있으면 검사부터 넣은 다음 화면을 고친다.

## 4. 조회 영역

| 번호 | 규칙 | 구현 | 검사 |
|---|---|---|---|
| **UI-01** | 목록·통계 화면의 조회 조건은 **반드시 공통 조회 영역 `WsSearch`로 만든다.** 제목은 '조회', 버튼은 제목줄 오른쪽(초기화 아이콘 + 조회(F2))이다. 자체 폼(`.cond`, '조회 조건' 제목, 폼 끝의 조회 버튼)은 쓰지 않는다 | `src/ws/WsSearch.vue` | `check:sb` UI-01 |
| **UI-02** | 조회 라벨 칸은 **글자 폭에 맞춰 자동으로 늘어난다.** 같은 열의 라벨은 가장 긴 라벨 폭으로 맞춰지고, 입력 칸은 남은 폭을 똑같이 나눈다. 화면은 라벨 폭을 정하지 않는다. 입력 칸 폭이 꼭 필요하면 `:cols`의 홀수 번째로만 준다. **조회 영역 안 인라인 `style="width…"`는 금지**다 | `WsSearch.vue` colStyles, `layout.css` | `check:sb` UI-02, 라벨 8자 초과 경고 |
| **UI-03** | 참여년도·사업은 **상단 바의 전역 조건**이다. 화면 조회 영역에 다시 두거나 `ref(ctx.year)`처럼 한 번만 복사하지 않는다. 전역 조건이 바뀌면 다시 조회한다(`watch(ctxKey)`). 여러 해를 비교하는 통계는 전역 조건과 뜻이 다르므로 **'비교 연도'** 조건으로 따로 둔다 | `src/sp/context.ts` | `check:sb` UI-03 |
| **UI-04** | 선택 상자의 '전체' 선택지 값은 빈 문자열이 아니라 **`'ALL'`**이다. 빈 값이면 선택 안 된 흐린 칸처럼 보인다. 필터는 `x === 'ALL' \|\| row.k === x`로 비교한다 | 화면 | `check:sb` UI-04 |
| **UI-05** | 기간 입력(달력 두 개 + 빠른 기간 버튼)은 한 덩어리로 두고, 버튼 글자는 줄바꿈하지 않는다. 모자라면 빠른 기간 버튼 묶음이 통째로 다음 줄로 간다 | `src/ws/WsPeriod.vue` | `check:responsive` |

## 6. 목록 · 표

| 번호 | 규칙 | 구현 | 검사 |
|---|---|---|---|
| **UI-07** | 표 칸(`td`·`th`) 자체에 `display:flex`를 걸지 않는다. 그러면 칸이 표 줄에서 빠져나와 선이 틀어진다(팝업 목록 사례). flex는 **칸 안쪽 `<div>`**에 건다 | 화면 | `check:sb` UI-07 |
| **UI-14** | 목록의 제목 링크는 **한 줄 말줄임**으로 두고, 전체 글자는 `title`로 보여 준다. 옆에 붙는 배지는 줄어들지 않는다(`flex: none`) | 화면 | `check:responsive` 버튼 글자 줄바꿈 |
| **UI-15** | 칸 안에 배지를 넣으면 **칸 폭을 배지가 들어가게 잡는다.** 배지가 칸 밖으로 나가면 안 된다(자료 목록 '기업 어드민 출력' 사례) | 화면 | `check:responsive` 영역 밖 글자 |
| **UI-16** | 카드 안 HTML 표(`.ws-gtb`)의 머리칸은 줄바꿈하지 않는다. 표가 카드보다 넓으면 **`.ws-xscroll` 틀로 감싸 가로 스크롤**한다. 목록 그리드(Tabulator)는 자체 스크롤이 있다 | `layout.css` | `check:responsive` 영역 밖 글자 |
| **UI-18** | 쪽 번호 버튼은 최소 32px이고 글자만큼 늘어난다. 두 자리 번호가 꺾이지 않는다 | `src/ws/WsPager.vue` | `check:responsive` 버튼 글자 줄바꿈 |
| **UI-19** | 차트 범례를 아래에 두면 축 라벨과 범례가 들어갈 아래 여백(56px)을 **기본으로 준다.** 화면이 따로 맞출 필요가 없다 | `src/app/EzChart.vue` | — |
